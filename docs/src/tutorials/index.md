# Tutorials

The tutorials are worked examples that walk you through solving a problem with FerriteGismo
step by step. They assume some familiarity with the finite element method and with the
[Ferrite.jl](https://ferrite-fem.github.io/Ferrite.jl/stable/) workflow; if you are new to
Ferrite, its
[tutorials](https://ferrite-fem.github.io/Ferrite.jl/stable/tutorials/) are a good starting
point, since FerriteGismo deliberately mirrors the same API.
