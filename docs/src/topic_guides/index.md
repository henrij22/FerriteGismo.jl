# Topic Guides

The topic guides explain one building block of FerriteGismo at a time. Unlike the
[Tutorials](../tutorials/index.md), they do not solve a problem from start to finish; they
describe what a piece of the API does, how it differs from its Ferrite counterpart, and what
to watch out for.
